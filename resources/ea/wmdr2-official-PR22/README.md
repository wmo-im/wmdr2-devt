# WMDR2 UML Diagram for PR#22

PR#22 proposes some modifications to the official WMDR2 schema [0]. Here, we have converted the schema into a UML diagram by way of translating it into an EA XMI 2.1 which can then be imported into Enterprise Architect. The UML diagram can be used to visualize the schema, specifically the feature types and cardinalities linking them. There are 2 diagrams:

- resources/ea/wmdr2-PR22/wmdr2-core-pr22.png
- resources/ea/wmdr2-PR22/wmdr2-supporting-types-pr22.png

As discussed in the comments of PR#22, the proposed modifications are not yet sufficient to align the schema with the more comprehensive UML model for WMDR2 [1], and there are a few naming differences that need to be resolved.:
